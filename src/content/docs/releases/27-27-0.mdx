**Release Date:** 2026-07-29

**Version Range:** v27.16.1 -> v27.27.0

## Highlights

- Enhanced feed creation tools for easier population and validation.
- Improved connector performance and reliability.
- Fixed several bugs to ensure a smoother user experience.

## What's New

### Features

- **Feed Creation:** You can now use enhanced tools to create, populate, and validate feeds more efficiently, reducing setup time and improving accuracy.

### Improvements

- **Connector Performance:** Connectors now load and sync data faster, improving overall system responsiveness.
- **User Interface:** Minor updates to the interface make navigation and workflows more intuitive.

### Bug Fixes

- Fixed an issue where certain feeds were not displaying correctly after creation.
- Resolved a problem where some connectors failed to sync under specific conditions.
- Addressed a rare issue that caused unexpected errors during agent configuration.

### Breaking Changes

None in this release.

## Customer Impact

None in this release.
