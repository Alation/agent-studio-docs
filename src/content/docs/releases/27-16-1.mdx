**Release Date:** 2026-07-22

**Version Range:** v27.0.0 -> v27.16.1

## Highlights

- Improved feed creation tools for faster and more accurate workflows.
- Enhanced connector details for better visibility into integrations.
- Resolved several bugs to improve overall stability and performance.

## What's New

### Features

- **Feed Creation:** You can now use enhanced tools to create, populate, and validate feeds more efficiently, reducing setup time and errors.
- **Connector Insights:** Additional details are now available for connectors, giving you deeper visibility into their configurations and statuses.

### Improvements

- **Performance:** General performance improvements across the platform ensure faster response times and smoother user experiences.
- **UI Enhancements:** Minor updates to the interface make navigation and workflows more intuitive.

### Bug Fixes

- Fixed an issue where feed validation occasionally failed under specific conditions.
- Resolved a problem that caused connector details to display inconsistently in some cases.
- Addressed a rare bug where certain chat contexts were not preserved correctly during agent interactions.

### Breaking Changes

None in this release.

## Customer Impact

None in this release.
